# FaceTrack decision-trace figure

This directory contains the public system-and-decision overview and the evidence used to construct it.

| File | Purpose |
| --- | --- |
| `contract.md` | Supported claim, selection rule, and evidence boundary |
| `provenance.json` | Capture origins, source revision, and checksums |
| `editable/facetrack-decision-trace.pptx` | Editable vector-and-screenshot source |
| `exports/facetrack-decision-trace.svg` | README-ready vector export |
| `exports/facetrack-decision-trace.png` | Raster review export |
| `exports/facetrack-decision-trace.pdf` | Print/preflight artifact |
| `media/session-workspace-demo.png` | Complete deterministic demo workspace capture |
| `media/session-workspace-figure-crop.png` | Selection used in the dominant evidence panel |
| `media/attendance-demo.png` | Deterministic attendance view capture |
| `preflight/preflight.json` | Automated PDF structure and placement-width report |
| `preflight/pptx-inspect.ndjson` | PowerPoint object and layout inspection output |
| `preflight/facetrack-decision-trace-readme-scale.png` | Final-size readability check at 716 px |
| `preflight/facetrack-decision-trace-grayscale.png` | Grayscale hierarchy check |

The captures come from the repository's default `DemoApiProvider`. The classroom frame is fictional and the decisions are bundled fixtures; neither is native recognition evidence. The SVG is the README asset, the PDF is the print artifact, and the PowerPoint retains editable text and geometry. See `contract.md` for the complete boundary.
