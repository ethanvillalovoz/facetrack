# Code Of Conduct

## Our Standard

Contributors are expected to communicate respectfully, give constructive feedback, and keep project discussions focused on improving FaceTrack.

## Unacceptable Behavior

Harassment, personal attacks, discriminatory language, doxxing, and sharing private biometric data or credentials are not acceptable.

## Enforcement

Project maintainers may edit, hide, or remove comments, issues, pull requests, or contributions that violate this code of conduct.

## Reporting

Report concerns to the repository owner through GitHub. For sensitive security or privacy issues, use the process in [SECURITY.md](SECURITY.md).
